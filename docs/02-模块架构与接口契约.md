# 02 模块架构与接口契约

当前实现合同，2026-11-20 / 0.8.0。历史设计不构成当前API；每轮测试与实机边界见08，最新重构细节见[29](29-会话就绪与能力模块重构.md)。

## 分层

| 模块 | 实际职责 | 不承担的职责 |
|---|---|---|
| cast-domain | 实际协商Profile | I/O、平台API、线程 |
| cast-core | 纯时间RTC恢复策略 | 编解码、SOAP、UI |
| cast-adapters | WSS/TLS、mDNS、按feature选择的DLNA/HTTP/TS/档案 | 平台采集和界面 |
| cast-ffi | 整数句柄、C ABI/JNI、边界校验 | UI、播放器、逐像素处理 |
| windows/media、Android媒体模块、Apple Shared/Media | 平台采集、编解码和RTC | 配对凭据、产品界面 |
| media-native | 固定FFmpeg子集TS封装 | 完整播放器和系统采集 |
| 平台组合层 | 用户授权、目标选择、会话及资源生命周期、状态展示 | 协议解析与媒体格式转换 |
| airplay-native | 独立GPL接收协议库 | Apache核心依赖、Android UI |

控制传输不得依赖runtime、DLNA、直播或HTTP资源适配器。领域和纯策略不得引用具体平台。scripts/check-architecture.py检查上述边界；构建feature按29选择，不使用旧legacy别名。

## 本机命令与事件

命令经有界32项队列提交；stop/shutdown有独立撤销通道。Engine在入队时标记generation，过期工作不能提交新资源。事件邮箱上限256项/2MiB，溢出撤销引擎并保留一个terminal错误；宿主有界批量消费。

| 命令 | 对应事件/语义 |
|---|---|
| listen / invite / approve | receiver.ready、receiver.invite、pair.request；一次性邀请与接收端明确确认 |
| scan / dlna.scan | devices / dlna.devices，必须回传scanGeneration；error字段区分搜索失败 |
| connect / send | connected、message、disconnected；send.message是已验证的当前线协议 |
| file.share | file.shared：url、length、mime、fingerprint、encrypted；桌面使用path，Android通过JNI shareFile传拥有的文件副本 |
| dlna.load / dlna.command | dlna.state含deviceId、action、结构化response或只读查询error；firstFrameMeasured=false |
| profiles.open / profile.check / probe.confirm / live.create | profile.checked、probe.saved、live.created/state/failed；带requestId/generation时须原样关联 |
| bridge.create / bridge.close | bridge.ready按requestId关联，关闭只影响匹配的播放器代理 |
| stop / shutdown | stopped / shutdown.completed；全局撤销媒体资源，宿主同时收尾搜索与平台媒体 |

错误含code、op、requestId、generation。command.rejected是未满足就绪条件的本机播放请求，含code=PLAYBACK_NOT_READY、requestId、sessionId，不关闭正常连接。裸整数fd不再作为JSON所有权传递接口。

## 自有线协议

C ABI当前版本2，配对方言v2；消息信封version=1，字段为id、type、sessionId、body及回复时的replyTo。不同层的版本号分别表示ABI、配对和信封，不能相互替换。只实现当前协议，不保留旧应用回退。

session.start.body为mode=file或mirror，镜像可携带rtcRecovery=replace-v1。session.accepted带当前sessionId与selectedProfile。file.load发送实际HTTPS资源描述，不再发送audioRequested、mediaId、durationMs等无人消费字段。

文件控制必须等session.state=ready。加载20秒超时、停止、错误或断连撤销该会话；reload/loading撤销可控制状态。播放/暂停、seek.positionMs和volume.value由接收端验证，播放命令不能作用于镜像会话。

镜像rtc.offer/answer/ice/state带当前negotiationId；更换传输带previousNegotiationId。旧协商的成功、ICE和错误不得影响当前媒体。恢复预算和重试次数由cast-core单独负责，详见12。

## 媒体与安全边界

自有控制与文件通过固定SPKI的TLS/WSS。配对码一次性使用，信任仅在当前会话；文件服务限定目标IP、随机资源地址、并发与连接期限。DLNA是局域网HTTP/SOAP，禁止重定向到任意地址，不会继承自有配对信任。

Android文件FD复制后由Rust RAII拥有；TS直接buffer仅在同步JNI回调期间借用，最终直播资源保留一份有界复制。C ABI所有返回buffer用lancast_free_buffer释放。宿主在等待线程退出后销毁句柄，不能用已销毁handle继续交付事件。

新增功能先明确命令、状态所有者、取消、过期事件及资源关闭责任，并补真正覆盖行为的契约测试。没有业务消费者的字段与包装函数不得作为预留扩展接口保留。
